🌐 Computer Networks — Beginner Notes

1. What is Data Communication?

Data communication = sending information from one device to another.

For example:

📱 Your phone → Wi-Fi → 🌐 Internet → 💻 YouTube server

The information could be:

Text

Pictures

Audio

Video

Files


Your presentation defines data communication as the exchange of data between two devices through a transmission medium such as a cable. 

The 5 basic parts

Think about sending a WhatsApp message:

1. Message → "Hello"

2. Sender → Your phone

3. Receiver → Your friend's phone

4. Transmission medium → Wi-Fi/mobile network/cable

5. Protocol → Rules that tell the devices how to communicate.



What is a protocol?

A protocol is simply a set of rules.

Just like humans need language and rules to communicate, computers need protocols.

Examples:

HTTP → web communication

TCP → reliable data delivery

IP → addressing and routing

SMTP → email sending

FTP → file transfer

2. What makes communication "good"?

Your presentation gives 4 important characteristics. 

① Delivery

Data must reach the correct device.

Example:

You send a message to Ali.

It should reach Ali, not Ahmed.

② Accuracy

The data should arrive without being corrupted.

You send:

> HELLO



It shouldn't arrive as:

> HXLLO



③ Timeliness

Data should arrive on time.

This is especially important for:

🎮 Online games
📞 Video calls
🎥 Live streaming

④ Jitter

Jitter = variation in the arrival time of packets.

Imagine you're watching a video call.

Packet 1 arrives after 20 ms
Packet 2 arrives after 20 ms
Packet 3 arrives after 500 ms
Packet 4 arrives after 30 ms

That uneven timing causes:

> 🔊 "Hello... ... ... can you hear me?"



That's jitter.

3. Data Flow

There are three ways devices can communicate:

Simplex

One direction only.

Think:

➡️

Example:

Keyboard → Computer

The keyboard sends information, but doesn't receive information from the computer.

Your presentation gives keyboard and monitor as examples. 


---

Half-Duplex

Both sides can communicate, but not at the same time.

Think about a walkie-talkie:

👤 A: "Hello!"

⬇️

👤 B: "Hello!"

⬇️

A speaks → B listens
B speaks → A listens




---

Full-Duplex

Both sides can communicate at the same time.

Think about a telephone call:

👤 A: "Hello!"

👤 B: "Hi!"

Both can speak and listen simultaneously.



Easy memory trick

Type	Direction

Simplex	➡️ Only one way
Half-duplex	↔️ Both ways, one at a time
Full-duplex	↔️ Both ways simultaneously

A network is a group of devices connected together so they can communicate.

For example:

💻 Laptop
↕️
📡 Wi-Fi Router
↕️
🌐 Internet
↕️
🖥️ Server

A device connected to a network is called a node.

A connection between devices is called a link.

The link can be:

Cable

Fiber

Radio/Wi-Fi

Other transmission media

7. Physical Layer

Layer 1

This is the lowest layer.

It deals with actual signals and physical transmission.

Think:

> "How do I physically send 0 and 1?"



For example:

Computer
   ↓
10101010
   ↓
Electrical / optical / radio signal
   ↓
Cable / Wi-Fi

The physical layer handles things such as bit representation, data rate, synchronization, physical topology, and transmission mode. 

Remember:

Physical = actual signals and wires/radio


---

8. Data Link Layer

Layer 2

Its main job is moving frames from one directly connected device to the next.

The important phrase is:

> Hop-to-hop



For example:

A → B → C → D

Data Link Layer handles:

A → B
B → C
C → D

not the entire journey at once.

It handles things like:

Frames

Physical/MAC addressing

Flow control

Error control

Access control




Easy memory:

Data Link = one step/hop


---

9. Network Layer

Layer 3

This layer is responsible for getting data from the source to the final destination.

Example:

Your laptop
     ↓
Router A
     ↓
Router B
     ↓
Router C
     ↓
Google server

The Network Layer decides:

> "Which path should this packet take?"



This is called routing.

It also uses logical addressing, such as IP addresses. 

Remember:

Network Layer = IP + Routing


---

10. Transport Layer

Layer 4

This layer handles communication between applications/processes.

Imagine your computer is running:

Chrome

WhatsApp

Discord

Spotify


All are using the network.

How does the computer know which application should receive the data?

It uses port numbers.

For example:

IP address → Which computer?
Port number → Which application?

The transport layer also handles:

Segmentation

Reassembly

Flow control

Error control

Connection control




Two very important protocols:

TCP
UDP


---

11. Session Layer

Layer 5

Think:

It establishes, maintains and synchronizes communication between systems.

Two important functions from your presentation:

Dialog control

Synchronization

12. Presentation Layer

Layer 6

Three major functions:

Original → 🔐 Encrypted → Network → 🔓 Original

Large file

Presentation = Translation + Encryption + Compression

⭐ 16. Switching Techniques

Now we move to another important topic.

There are three main switching techniques:

1. Circuit Switching


2. Message Switching


3. Packet Switching






---

17. Circuit Switching

Imagine a telephone call.

Before talking:

A ──────── B

The network establishes a dedicated path.

That path stays reserved until the call ends.



Advantage

Once connected, you have a dedicated communication path.

Disadvantage

If you're not talking, the reserved network resources can remain unused.

Your presentation also notes setup delay and inefficient use of the communication channel. 


---

18. Message Switching

Here the whole message is sent from one node to another.

Imagine:

A → Router 1 → Router 2 → B

Router 1 receives the entire message, stores it, then forwards it.

This is called:

> Store-and-forward





Problem

If the message is huge, routers need a lot of storage and the delay can be high.


---

⭐ 19. Packet Switching

This is extremely important because modern Internet communication uses packet-based networking.

Instead of sending one huge message:

HELLOWORLD

we divide it:

HEL | LOW | ORL | D

These pieces are called packets.

Each packet contains:

Data

Header/control information




Packets can potentially take different routes:

→ Router B →
       /             \
A ───                 → Destination
       \             /
        → Router C →

At the destination, they are put back together.

⭐ 21. Network Performance

Three words are very important:

Delay
Jitter
Throughput




---

Delay

Delay = how long data takes to reach the destination.

Your presentation gives:

Total delay = Processing + Queuing + Transmission + Propagation 

Processing delay

Router examines the packet.

Queuing delay

Packet waits in line.

Like waiting in a queue at a shop.

Transmission delay

Time needed to put all bits onto the link.

Propagation delay

Time for the signal to physically travel through the medium.


---

22. Throughput

Throughput = actual amount of data successfully transmitted per unit time.

Example:

Your Internet connection says:

> 100 Mbps



But your actual download speed is:

> 80 Mbps



Then:

Bandwidth = 100 Mbps

Throughput = 80 Mbps

Your presentation states that normally throughput is less than or equal to bandwidth.
