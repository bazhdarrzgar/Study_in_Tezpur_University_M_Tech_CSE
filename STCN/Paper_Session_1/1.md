## 🧠 Computer Networks — Last-Minute Memorization

**1. Data Communication:** It means **sending/exchanging data between devices** using a transmission medium. The 5 basic parts are **Message, Sender, Receiver, Transmission Medium, and Protocol**. A **protocol** is simply a set of rules used for communication. 

**2. Good Communication:** Remember **D-A-T-J** → **Delivery, Accuracy, Timeliness, Jitter**. Delivery means data reaches the correct device; Accuracy means data is not corrupted; Timeliness means data arrives on time; Jitter means **variation in packet arrival time**. 

**3. Data Flow:** **Simplex = one direction**, **Half-duplex = both directions but one at a time**, **Full-duplex = both directions at the same time**. Easy example: keyboard = simplex, walkie-talkie = half-duplex, telephone = full-duplex.

### ⭐ 6. Switching

There are **3 types**:

* **Circuit Switching** → dedicated path; example: traditional telephone.
* **Message Switching** → whole message is stored and forwarded; called **store-and-forward**.
* **Packet Switching** → message is divided into **small packets**; modern Internet uses packet-based networking. 

🧠 Remember:

**Circuit = dedicated path**
**Message = whole message**
**Packet = small pieces**

---

### ⭐ 7. Network Performance

Remember **D-J-T**:

**Delay** = how long data takes to arrive.
**Jitter** = variation in packet arrival time.
**Throughput** = actual amount of data successfully transferred per unit time.

**Total Delay = Processing + Queuing + Transmission + Propagation**

Also remember: **Throughput ≤ Bandwidth**.

### ⭐ 8. DNS

**DNS = Domain Name System.**

Its main job is:

**Domain name → IP address**

Example:

`google.com → IP address`

🧠 Think: **DNS = Internet phone book.**

Important records:

**A = IPv4**
**AAAA = IPv6**
**MX = Email server**
**CNAME = Alias**
**PTR = IP → Domain**
**NS = Name server**
**TXT = Text information**

### ⭐ 10. URL

**URL = Uniform Resource Locator.**

It is basically the **address of something on the Internet**. It can contain things such as the method, host, port, and path. 

---

### ⭐ 11. Overlay Network & P2P

**Overlay Network** = a **virtual network built on top of an existing physical network**.

**P2P (Peer-to-Peer)** = computers communicate directly and each computer can act as **both client and server**. Examples in your notes include **BitTorrent, original Skype, and blockchain networks**.
